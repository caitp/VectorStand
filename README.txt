This is a simple parametric synthesizer stand. It was originally designed for the Vector synthesizer (https://www.vectorsynth.com) but can be used for any other gear after changing the parameters.

The stand consists of two identical parts. When printed wide enough with the proposed rubber feet, the two parts are pressed down by the weight of the instrument so it does not need any connection between the parts as seen in similar designs (threaded rods etc.).

Components used for one part (two needed in total):

- 2× Anti-slip rubber (25×12mm): Fix & Fasten FIX-SF-152530
- 4× Bottom rubber feet (diameter 12.7mm): 3M Bumpon series SJ5012 (7000001884)

The source code and more details are available at https://github.com/adamheinrich/gear_stand.

The design uses the Round-Anything library (https://github.com/Irev-Dev/Round-Anything). Before modifying the OpenSCAD sources downloaded from Thingiverse, make sure to download the library and place it into directory "Round-Anything".
